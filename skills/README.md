# Skills

First-party skills: markdown know-how packages that teach agents to drive CLIs and APIs well via the native tools.

Skills carry **knowledge only** — a skill cannot grant permissions; the agent's config remains the sole authority on what is runnable and reachable.

- [`gh-issues`](gh-issues.md) — create and manage GitHub issues with the `gh` CLI (used by the [issue-bot](../examples/issue-bot/) example).
- [`looped-authoring`](looped-authoring.md) — scaffold and validate Looped agents with the `af` CLI (used by the [agent-zero](../examples/agent-zero/) example).
- [`looped-docs`](writing/looped-docs.md) — how to write docs and copy for Looped: voice, rules, and examples.
